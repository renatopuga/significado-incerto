# Checklist de publicação

## Texto e revisão

- [ ] Definir o manuscrito canônico.
- [ ] Concluir leitura crítica e preparação de texto.
- [ ] Concluir revisão ortográfica e prova final.
- [ ] Validar termos genéticos e notas técnicas.
- [ ] Verificar que não há dados pessoais ou clínicos identificáveis.
- [ ] Aprovar a declaração sobre assistência de IA.

## Metadados

- [ ] Confirmar nome autoral na capa e ficha.
- [ ] Aprovar sinopse curta e longa.
- [ ] Definir palavras-chave e categorias comerciais.
- [ ] Definir editora ou selo.
- [ ] Definir local e data de publicação.
- [ ] Obter ISBN específico para cada formato, quando aplicável.
- [ ] Atualizar `METADATA.yml` e `CITATION.cff`.
- [ ] Preparar ficha catalográfica, se adotada.

## Direitos e permissões

- [ ] Confirmar titularidade de texto, capa, imagens e fontes.
- [ ] Documentar permissões para citações e materiais de terceiros.
- [ ] Revisar os termos da plataforma ou contrato editorial.
- [ ] Definir territorialidade e formatos licenciados.
- [ ] Confirmar política sobre arquivos-fonte e material assistido por IA.

## Produção

- [ ] Finalizar capa para ebook.
- [ ] Finalizar capa completa e miolo para impressão.
- [ ] Gerar EPUB acessível e validar navegação.
- [ ] Gerar PDF de impressão com dimensões, margens e sangria corretas.
- [ ] Testar sumário, links, notas e fontes incorporadas.
- [ ] Revisar em dispositivo Kindle e/ou prova física.
- [ ] Gerar checksums SHA-256 dos arquivos finais.

## Release

- [ ] Atualizar versão para `1.0.0`.
- [ ] Preencher `CHANGELOG.md`.
- [ ] Criar tag anotada `v1.0.0`.
- [ ] Criar release privado com os artefatos aprovados.
- [ ] Registrar data, formatos, ISBNs e checksums.
- [ ] Arquivar cópia imutável dos arquivos publicados.

## Divulgação

- [ ] Preparar descrição comercial e biografia curta.
- [ ] Preparar press kit e imagens para redes.
- [ ] Definir página oficial e contatos.
- [ ] Planejar lançamento, preço e eventual promoção.
